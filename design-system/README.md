# Оформление исходной структуры

Единственный источник визуальных ролей: /Users/aleksandrklopov/Documents/CODEX/Чемпион/02_Current_Project/UI-KIT. tokens.css и components.css совпадают с ним. pages.css содержит компоновку страницы; старые CSS не подключаются.

Исходный состав и последовательность берутся из 18 сохранённых оригиналов. Изображения и логотипы остаются в своих блоках, медиа сохраняют сторону. При отсутствии файла используется нейтральная заглушка; декоративная геометрия не имитирует фотографию. Верхнее медиа карточки не имеет собственного нижнего радиуса, форму обрезает внешняя карточка.

Фото слева + материалы справа — ch-story--reverse ch-story--portrait: внутри текстовой колонки заголовок feature, описание, шесть плиток ch-document-list и исходные действия. Таблицы допустимы там, где исходник действительно содержит табличные характеристики; ими нельзя заменять фотоблоки документов.

Рубрики — ch-tabs/ch-tab, как фильтры товаров; на странице блога CSS переключает категории по фрагменту URL. Ссылки ch-link оранжевые на hover/focus. Стандартный FAQ — ch-faq; по отдельному замечанию блок гарантии about полноширинный. Формы с вводным текстом сохраняют две колонки на ПК и один поток на телефоне.

Демонстрационные данные и формы не подключены к серверу. Хедер/футер штатные в Ките. Старый sections/home-kit не является текущим дизайном этих страниц.
